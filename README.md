# Caesar Cipher Encryption

A simple Python program that encrypts words or sentences using a Caesar cipher. The program takes a user's message and shifts each letter by a specified number of positions in the alphabet. Uppercase letters are processed while spaces, numbers, and other characters are preserved. The program also allows the user to choose whether the final encrypted message should be displayed in lowercase or uppercase. This project is useful for practicing functions, string manipulation, lists, loops, indexing, and the use of Python's `string` module.

## Features

* Encrypts messages using a Caesar cipher.
* Allows the user to choose the shift amount.
* Preserves spaces, numbers, and special characters.
* Allows the final result to be displayed in lowercase or uppercase.
* Uses Python's built-in `string` module for alphabet handling.
* Demonstrates functions, loops, lists, indexing, and conditional statements.

## How to Run

1. Make sure Python 3 is installed.
2. Run the script:

   ```bash
   python caesar_cipher.py
   ```
3. Enter your name.
4. Choose whether the output should be lowercase or uppercase.
5. Enter the message you want to encrypt.
6. Enter the desired shift amount.

## Example

```text
Welcome to encrypting and decrypting your words/sentences
What's your name? John
Do you want your input to be in lowercase or uppercase? uppercase
Enter your message : HELLO WORLD
Enter your shift : 3

John, your encrypted word is KHOOR ZRUOG
```
